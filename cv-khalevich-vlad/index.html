Сайт с ERP‑системой для мебельного бизнеса

https://github.com/Ksaiko-Vlad/WebSofa2

Для клиентов реализован удобный каталог с возможностью выбора и оплаты товаров через интегрированный платёжный сервис. Лендинг для мобильного приложения TaskPlanner

https://github.com/Ksaiko-Vlad/It-planner-lending

Был разработан строгий и динамичный лендинг для презентации приложения-планировщика. Чтобы передать современный дух продукта, добавлены интерактивные элементы: фоновые частицы на Canvas (летающие шарики, реагирующие на движение мыши), плавные эффекты наведения на карточки функций и слайдер для демонстрации экранов приложения.

TypeScript React.js HTML/CSS JavaScript Canvas API

Лендинг для функционального питания котов Cat Energy

https://github.com/Ksaiko-Vlad/Cat-Energy

Разработан яркий и информативный лендинг для бренда специализированного корма. Чтобы наглядно показать эффективность продукта, был создан интерактивный блок с «живой» картинкой кота, демонстрирующей изменения «до и после» перехода на питание. Для удобства пользователей реализована адаптивная верстка под все типы устройств с бургер-меню, добавлены визуальные эффекты при наведении на карточки товаров, а для локации точек продаж подключена API Яндекс карт.

HTML CSS JavaScript Yandex Maps API

Help-desk — корпоративный портал заявок на обслуживание техники

https://github.com/N0Pr0blem/Help-Desk/tree/feature/frontend-init

Разработан внутренний корпоративный портал для автоматизации приёма и обработки заявок на ремонт оргтехники и обслуживание ПК. В системе реализована авторизация и разделение на три роли: сотрудники могут быстро создать заявку о поломке (не работает ПК, сломался принтер и т.д.), сисадмины — брать свободные заявки в работу и отмечать их выполненными, а администраторы — управлять пользователями (назначать роли, блокировать, создавать новых) и отслеживать все заявки на каждом этапе. Интерфейс полностью адаптирован под планшеты и телефоны.

React JavaScript HTML/CSS PostgreSQL Spring Framework Java
